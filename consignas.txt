Documentación del Trabajo Práctico: Chatbot Escolar con IA 
1. Introducción y Contexto 
El objetivo de este trabajo práctico es diseñar, programar e implementar un asistente virtual (Chatbot) capaz de resolver dudas recurrentes sobre trámites administrativos y académicos de nuestra escuela técnica. El sistema procesará el lenguaje natural de los usuarios mediante una red neuronal en Python y se expondrá como un servicio en red (API) para ser integrado en la página web de la institución. 
2. Requerimientos Fun13cionales (RF) 
Los alumnos deberán garantizar que el sistema cumpla estrictamente con las siguientes funciones: 
RF-01: Procesamiento de Lenguaje Natural (PLN): El bot debe entender la intención del usuario final, incluso si introduce errores ortográficos, abreviaturas o sinónimos (ej: "constancia de alumno", "certificado regular", "papel para la obra social" deben activar la misma respuesta). 
RF-02: Gestión de Trámites Técnicos: El sistema debe responder de forma precisa, como mínimo, a los siguientes ejes temáticos: 
O 
Requisitos y fechas para Prácticas Profesionalizantes / Pasantías. 
Protocolo de seguridad y uso de herramientas en Talleres y Laboratorios. Mesas de examen (previas y equivalencias). 
Emisión de documentación (constancia de alumno regular, analíticos). 
RF-03: Interfaz de Programación de Aplicaciones (API REST): El backend en Python debe exponer un endpoint HTTP (por ejemplo, /chat mediante método POST) que reciba la pregunta del usuario en formato JSON y devuelva la respuesta procesada por la IA. 
RF-04: Respuesta por Defecto (Fallback): Si la red neuronal no logra superar un umbral mínimo de certeza (ej. menos del 60% de coincidencia), el bot debe responder con un mensaje genérico amable y derivar a un correo institucional o preceptoría.
